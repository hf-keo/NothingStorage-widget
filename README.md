# Nothing Storage Widget

Android home-screen storage widget with a dark Nothing-inspired interface, dot-matrix storage percentage, storage fullness bar, adjustable opacity, and accent colors.

## Download APK

Open **Actions → Build Android APK → latest successful run → Artifacts** to download the debug APK ZIP. Extract `app-debug.apk`, install it on Android, then long-press the home screen and select **Widgets → Nothing Storage**.

The APK is only available after a successful GitHub Actions build. Debug builds are for testing; a production release should use a stable signing key.

No official Nothing fonts are included; dot-matrix glyphs are original.
